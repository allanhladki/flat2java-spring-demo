# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

This is a demonstration application. `GET /file` reads any file that the application process can
read, by design. Do not deploy it on a network you do not control.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/allanhladki/flat2java-spring-demo/security/advisories/new).
Do not open a public issue.

Vulnerabilities in the flat2java library itself should be reported to the
[flat2java repository](https://github.com/allanhladki/flat2java/security/advisories/new).

Include the affected version, a description of the problem and, if possible, a minimal
reproduction. Once a fix is released, the advisory is published with credit to the reporter,
unless you prefer otherwise.
