flat2java Spring Boot demo

Reads fixed-width records (COBOL-style flat files) into objects and writes them back, with flat2java and its Spring Boot auto-configuration.

    Swagger UINamed examples for every endpoint, ready to execute OpenAPI documentYAML; the JSON is at /swagger Health/health, /health/live and /health/ready InfoApplication, flat2java, Spring Boot and Java versions

    Try it

    The record on the left is the 315-column SampleModel of samples/typical.txt. Read turns it into JSON; edit the JSON and press Write to get the record back.

    Endpoints

    Method and pathRequestResponse
    POST /readtext/plain, one recordapplication/json
    POST /writeapplication/json, a SampleModeltext/plain; charset=UTF-8
    GET /file?path=Path of a UTF-8 file on the serverapplication/json
     

    curl -X POST http://localhost:8080/read --data-binary @samples/typical.txt
